## Prediction

What do you expect before running the experiment, and why? Name the variable you will change and the variables you will hold fixed.

## Execution

Record the exact command, configuration, seed, split and output directory. Record failed attempts as well as successful ones. Do not include passwords or access tokens.

## Evidence

Link the raw log, images or replay, result summary and relevant tests. Include one concrete value with its unit. For GPU work, retain the resolved model revision, package versions, device, runtime and memory measurement.

## Interpretation

Explain one observation using an image, log row or computation. Did it match the prediction? Distinguish the requested action, accepted command and measured response.

## Failure and correction

Record one observed or deliberately injected failure, the expected handling and the actual handling. State whether the correction changed the data, software, protocol or environment.
